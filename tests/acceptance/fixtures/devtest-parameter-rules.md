# 创建标签参数规则

## API

POST /api/tags

公开接口，无需认证。

## Body 参数

| 参数 | 位置 | 类型 | 必填 | 可空 | 最小长度 | 最大长度 | 枚举 | 格式 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| name | body | string | 是 | 否 | 1 | 20 | | ^[a-z0-9-]+$ |
| color | body | string | 是 | 否 | | | red,green,blue | |

## 响应

| 状态码 | 描述 |
| --- | --- |
| 201 | 创建成功 |
| 400 | 参数非法 |

## Acceptance Criteria

- AC-1 name 长度 1 和 20 时创建成功返回 201。
- AC-2 name 为空、长度 21 或格式非法时返回 400。
- AC-3 color 不在枚举中时返回 400。
