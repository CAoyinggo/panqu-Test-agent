# Panqu NewAPI 与分流边界约束检查表

| 维度 | 检查项 | 约束规则与预期行为 | 违规或异常处理 |
|---|---|---|---|
| **全量开关** | is_newapi_global | 1 表示开启走 NewAPI，0 表示走主站旧直连 | 必须同时验证 1 与 0 两种状态的分流流向 |
| **用户分组资格** | group / token | 请求用户必须属于对应分组 (如 panqu_test) | 未授权分组返回 PERMISSION_DENIED 或走默认组织线路 |
| **渠道权重** | weight (1~100) | 多供应商渠道按权重比例分流 (如 50:50) | 权重为 0 的渠道不得接收流量 |
| **模型能力联动** | ability | 仅支持首尾帧的模型传入参考视频时需拦截 | 接口在参数校验阶段返回 400 PARAMETER_CONFLICT |
| **幂等键** | idempotency_key | 保证同一任务请求在新API网关处只创建一次 | 网关去重避免多次调用上游计费供应商 |
