## 数据规则

1. 数据项必须追溯到 Requirement Fact、Business Flow Step 或 Evidence Requirement。
2. 身份、凭据、环境地址和 Secret 只保存安全运行时引用。
3. 动态资源标识由 Prepare 或前序 Step Capture 产生，不使用模板默认值。
4. 可变数据必须明确 Actor、Owner、Tenant、Project、Run ID 和 Cleanup Hook。
5. Before-state 与 After-state 必须来自独立 Observer；不能用预期值冒充实际状态。
6. 缺少 required 数据、归属或清理能力时，Runtime Readiness 必须为 `BLOCKED`。

## 数据隔离检查

- [ ] Case 使用独立或明确归属的数据。
- [ ] 多 Actor/Tenant/Project 数据不会共享隐式全局变量。
- [ ] Cleanup 只处理当前 Run 创建或声明可修改的数据。
- [ ] Cleanup 结果产生 Evidence。
- [ ] 后续 Case 能证明不存在 Cross-Case Pollution。
