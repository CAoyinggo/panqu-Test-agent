# Panqu 真实测试与最低积分偏好

来源：用户于 2026-09-09 明确要求测试真实执行，尽量少消耗积分；视频优先最低画质、最短时间；输入文案和上传素材可由助手准备，也可使用用户指定的本地文件夹。

## 默认执行要求

- 需要生成的业务验收必须走真实产品链路，追踪任务至结束，并核对实际结果资产及可获得的扣费记录。模拟数据、HTTP 200 或任务 ID 不能替代生成成功。无法真实执行时保留 BLOCKED/NOT_EXECUTED。
- 在待测模型、模式和本轮用例要求不变的前提下，使用当前支持的最低成本合法组合。普通视频冒烟优先最低画质/分辨率、最短时长、单条输出；图片优先最低成本合法尺寸与单张输出。先核对当前能力和产品计费/报价，不能假设最低分辨率必定最便宜，不能固化价格和参数下限。
- 不得为省积分换成另一个模型或模式。明确要求验证高清、长时长、批量或参数上边界的用例不能降档后报通过；先列出其必要成本，预算不足时保留未执行项。
- 先完成无扣费的输入、权限、绑定和环境检查，再执行必要的最小真实冒烟；只有确认的测试范围内才增加调用。避免重复提交。任务超时先查询原任务和扣费状态，不能立即重试生成。
- 执行计划列出每项参数、预计积分、任务数、素材和总预算。价格未知、扣费状态不明、余额不足或可能超预算时暂停；未知扣费不按零计。一次确认覆盖同一计划内的授权执行，不能静默扩大预算或范围。

## 素材准备

- 助手可准备简短、可判断结果的测试文案，以及不含个人隐私、凭证或商业机密的合成素材。素材必须满足当前模型的真实输入限制；准备本地素材与调用付费模型生成素材分开计费、分开说明。
- 用户指定本地文件夹后，只在指定范围内选择相关素材；没有指定时不扫描整台电脑寻找文件。选定上传文件在计划中列明，不能将目录授权理解为上传整个目录。
- 原始素材只读；需要裁剪、缩短、压缩、改名或格式转换时使用副本，保留原文件。仅上传用例需要的文件。付费素材生成同样计入已确认预算。
- 有效输入使用尽量小而合规的素材；非法输入或上下界用例按实际要求独立准备，不能通过压缩或裁剪消除待测的边界条件。

## 当前实现状态与授权边界

v4.31.0 的[自主准备](panqu-mission-preparation.md)已接通 Nuxt 文生视频单节点的当前能力、节点和完整候选报价读取，并在提交前重新核对。无需模型手写 catalog/payload/参数指针；它只在已确认输出范围内选最低真实报价，不把省积分偏好当作生成授权。PHP 自动准备仍缺少完整能力/报价契约。

v4.30.0 已将最低成本选型、同计划预算授权、单次提交、任务恢复、实际媒体解码和任务扣费核对接入独立 Mission 控制器。它支持操作员配置的 PHP 视频 multipart 和 Nuxt 单节点 JSON 协议；原 MCP 仍为 SAFE 只读入口。目录素材识别和本地小型合成视频准备已实现；参考文件上传仍缺少经核对的资产上传适配器，不能把本地文件直接塞进前端的已上传资产引用字段。真实能力/报价与扣费接口必须由当前项目确认，不能从模型猜测中获得。详见 [Mission 使用说明](panqu-mission.md)。

此偏好不是无限扣费授权。首次真实付费测试前仍需明确目标环境、账号权限、本轮总积分上限和测试范围；素材目录可选。已确认预算内的同一计划无需逐条重复确认，发生范围、成本或授权变化时再确认。不得借生产账号或其他来源绕过缺失权限。
