# Panqu 项目专属内核（v4.29.3）

## 模型与确定性执行的分工

模型负责理解需求、定位需要核对的调用链、提出必要澄清和解释结果。内核独立读取源码并检查计划绑定；模型遗漏项目约定时，执行器不会仅凭模型判断放行已知冲突。没有需求依据时不能从源码自动补成产品规则。

`runDevTest` 每次重新生成项目指纹，合并到发现缓存的校验键；MCP 计划另包含 Vue 文件内容。`devtest inspect-project` 无需配置或 MCP 即可输出同一观察结果。检查只读取项目，不执行应用脚本或付费请求。

## 当前具备的能力

- 通过依赖及结构入口分别识别 Nuxt/Vue Flow 与 Next/XYFlow，不依赖仓库名，不混用节点或接口协议。
- AST 读取具名导入及别名、类型参数调用、显式 HTTP 方法、静态路径、FormData/JSON body、Nuxt 插件 kind、导入反向影响链。注释和字符串不是调用；已识别的参数/局部变量遮蔽不算 wrapper 调用。
- 简单、可核对的 fetch options 转发才能认定默认 GET。动态方法、spread options 不猜成 GET。源码包含上限、解析错误、符号链接等诊断，不能静默宣称完整。
- 执行前阻断方法冲突和不支持的 multipart 绑定，包括环境探测。保守地阻断整个本轮，保留冲突，不改写原始需求。
- 内置 HTTP 执行器核对已识别的 PHP/Go 客户端响应条件。HTTP 完成但源码协议拒绝时，保留原请求/响应和通过的传输断言，结果降为 BLOCKED/UNCONFIRMED，而非伪造产品失败。显式 code 断言及非 2xx 负向预期仍由需求 Oracle 判断。自定义场景 Processor 尚缺相同证据适配时阻断，不能绕过检查。
- Git 工作区变化经导入反向传播，列出受影响的本地回归候选；候选固定为 NOT_EXECUTED。未知测试类型统一标为 UNCLASSIFIED_LOCAL_TEST，不假称交互验证。

## 有意保留的边界

v4.31.0 新增独立的[自主任务准备](testing/panqu-mission-preparation.md)：Nuxt 文生视频单节点自动读取能力、节点与候选报价并绑定执行计划。该适配器的相关源码就绪不等于全项目解析完整，也不会解除普通 DevTest 门禁。

用户已指定[真实执行、最低积分和可指定本地素材目录的测试策略](testing/panqu-low-cost-real-execution.md)。v4.30.0 在独立的 [Mission 控制器](testing/panqu-mission.md) 中实现受明确授权约束的生成闭环；本页描述的普通 DevTest/MCP 路径继续保持原有只读边界。

这不是完整 TypeScript 类型解析器或应用编译器。动态 URL、复杂参数合并、Nuxt 自动导入、再导出链、运行期配置、PHP/Go 服务端源码和真实 provider 行为尚不能完整绑定。SFC 仅提取 script，完整原文件进入指纹；不校验模板运行行为。已识别客户端条件只是源码观察，不等同后端或产品契约。

默认最多 3000 个源码文件、单文件 1 MiB、20000 个目录项。隐藏工具目录、依赖、构建产物不参与项目图；不跟随符号链接。不读取 `.env`。代码图不执行任意项目测试命令。缺失环境、规则、身份、Observer、真实资产或结算证据，依然不能宣称业务通过。

2026-09-09 对两个实际前端进行了只读校验：aiworkflow 识别 1596 个源码文件、142 个请求调用、14 个插件 kind、57 个测试候选；其中 AudioPlayer.vue 存在源码解析诊断，完整性为 false。aidrawos 识别 126 个源码文件、13 个请求调用，未找到本地测试候选。以上是当时工作区的实现观察，不是业务测试结果，也不应当作为未来固定数量断言。
