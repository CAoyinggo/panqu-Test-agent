# 测试用例模板

> 使用说明：复制本模板，将「{占位符}」替换为实际内容。每条用例一行核心信息，详细步骤在说明列。执行方式：`API`=脚本自动 / `浏览器`=人工页面操作 / `SQL`=查库验证。

## 用例详情示例

> 以下示例以 `wan3`（视频生成）为例，仅作演示。`{...}` 占位符按实际业务替换；wan3 专属的模型 ID、任务类型编码、参数等请在您的业务中替换为对应值（详见每条用例末的「示例值」）。

### 用例：{MODULE}-FUN-01 提交{业务类型}任务

- **优先级**：P0
- **前置条件**：已登录 test 环境、账号积分充足（≥{预计扣费}）、{模型名}可用
- **步骤**：
  1. 进入{业务}制作页（{入口 URL}，示例：`/aivideo/v2/videohub/pipeline?project_id={项目ID}`）
  2. 选择模型 {模型名}（model_id={模型ID}）
  3. 选择任务类型 {任务类型}（task_type={任务类型编码}）
  4. 输入{输入内容}：{提示词内容}
  5. 设置参数：{分辨率} / {时长} / {比例}
  6. 提交任务
- **预期结果**：
  - 提交接口返回 `code=1`
  - 返回任务 ID
  - 任务落库：model_id={模型ID}、type={业务类型编码}、extra.{参数字段名}="{参数值}"
  - 积分扣费 {预计扣费}
- **执行方式**：API（脚本自动）
- **示例值（wan3，仅演示）**：project_id=365、model_id=84、task_type=105、720p / 4秒 / 9:16、预计扣费 240 积分

### 用例：{MODULE}-BILL-02 失败积分回退

- **优先级**：P1
- **前置条件**：存在一个失败任务
- **步骤**：
  1. 查询任务状态，确认 task_status=3（失败）
  2. 查询账单明细 records
- **预期结果**：
  - 出现一对流水：消费 -{预计扣费}、回退 +{预计扣费}
  - 净消耗 0
- **执行方式**：API（脚本自动）
