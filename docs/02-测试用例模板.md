# DevTest 通用测试用例模板

> 本模板描述“如何表达一个测试”，不描述任何特定功能应该如何测试。引擎字段权威见 [TEST_CASE_V2 Schema](testing/testcase-v2-schema.md)。

## 5. Dynamic Test Dimensions

仅勾选由 Requirement、Business Flow、State、Rule 或 Risk 触发的能力：

- [ ] Functional
- [ ] UI
- [ ] API
- [ ] Parameter Validation
- [ ] Boundary
- [ ] Exception
- [ ] Permission
- [ ] Data Isolation
- [ ] State Transition
- [ ] Data Consistency
- [ ] Idempotency
- [ ] Concurrency
- [ ] Side Effect
- [ ] Failure Recovery
- [ ] Cross-Case Pollution

每个选择必须记录触发 Fact 和 proof obligation。没有触发依据时不得生成。
