## 用例详情示例

### 用例：WAN3-FUN-01 提交文生视频任务

- **优先级**：P0
- **前置条件**：已登录 test 环境、账号积分充足（≥240）、Wan 3.0 模型可用
- **步骤**：
  1. 进入视频制作页（`/aivideo/v2/videohub/pipeline?project_id=365`）
  2. 选择模型 Wan 3.0（model_id=84）
  3. 选择任务类型 全能参考（task_type=105）
  4. 输入提示词：{提示词}
  5. 设置参数：720p / 4秒 / 9:16
  6. 提交任务
- **预期结果**：
  - 提交接口返回 `code=1`
  - 返回任务 ID
  - 任务落库：model_id=84、type=6、extra.selmodelsName="Wan 3.0"
  - 积分扣费 240
- **执行方式**：API（脚本自动）

### 用例：WAN3-BILL-02 失败积分回退

- **优先级**：P1
- **前置条件**：存在一个失败任务
- **步骤**：
  1. 查询任务状态，确认 task_status=3（失败）
  2. 查询账单明细 records
- **预期结果**：
  - 出现一对流水：消费 -240、回退 +240
  - 净消耗 0
- **执行方式**：API（脚本自动）
