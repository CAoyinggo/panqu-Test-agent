# 项目说明模板（README-项目说明.md 统一格式）

> **LEGACY 交付包模板**：本文仍记录历史 `tasks/*.json` / `run-test` 交付包格式，不是当前 DevTest 用例生成或执行协议。新任务使用 [TestCase V2 字段与生成规则](testing/testcase-v2-schema.md) 和 [`npm run devtest`](devtest.md)；下文仅供老资产迁移参考，不得将“生成 HTML/待人工”报告为已执行。
>
> 版本：v2.1 ｜ 更新：2026-08-16 ｜ 维护：AI 测试智能体
> **通用格式模板**：适用于任何业务功能模块（如 user、order、payment 等）的交付包项目说明。
> **通用模板说明**：本模板为通用项目说明模板，使用时请将所有 `{占位符}` 替换为实际业务数据。示例以 `wan3`（视频生成）业务为例，仅作演示，实际使用时请替换为您的业务名（如 user、order、payment）。
> 使用方式：复制本模板到交付包目录，命名为 `README-项目说明.md`，将 `{占位符}` 替换为本次功能实际内容，删除「填写说明」段落。

## 使用说明

1. 按下方章节顺序生成项目说明，**章节结构与编号保持不变**（这是统一格式）。
2. 每章节的「填写说明」只用于解释该章节写什么，交付时删除。
3. 「填写示例」仅作格式参考，替换为本次功能实际数据。
4. 生成完成后，对照文末「必填项检查清单」逐项核对。
5. 交付包内同时提供 `README-项目说明.md`（Markdown 版）与 `README-项目说明.html`（HTML 报告版），内容保持一致。
